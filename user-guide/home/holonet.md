# Holonet

The Holonet is a hub where community members can share conventions and signing events with other community members.

## Submit Event

<img width="227" height="83" alt="submit-event" src="https://github.com/user-attachments/assets/9b76585b-b285-4357-a3c3-9bed2b1c2780" />

Clicking **Submit Event** opens the event submission form.

## Submit Holonet Event

<img width="692" height="579" alt="create-holonet-event" src="https://github.com/user-attachments/assets/5d3e69db-457e-4281-90da-6c4f683a8d7d" />

The **Create HoloNet Event** form allows users to submit event details, including title, date, location, description, related links and attending authors.

## Holonet Event

<img width="1066" height="137" alt="submitted-event" src="https://github.com/user-attachments/assets/4e871df3-c26f-4a45-aa53-2e75934062d4" />

The event submitter is able to edit and delete their submitted event.

<img width="1063" height="114" alt="non-submitted-event" src="https://github.com/user-attachments/assets/3d6024a6-7fd0-4806-975a-444e764ae7a4" />

When viewing events submitted by other community members, you won't see the edit or delete buttons.

<img width="1064" height="117" alt="added-event" src="https://github.com/user-attachments/assets/33fa448f-e3bf-42cb-8376-62d9d4b35ce0" />

Clicking on the bookmark button will add the Holonet event to your "My Events" page, this creates a copy of the event in your private event log.

## Searching & Filtering Events

You can search events by attending author and also apply filters based on the event name.
