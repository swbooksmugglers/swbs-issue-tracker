# Catalog

The catalog is the complete archive of Star Wars books in the database, every title automatically loaded when you open the page. Think of it as browsing the full library.

What you can do:

* Filter the catalog using with the filter feature, narrow down by title/author text search, publisher, format, series, sub-series, era, continuity, exclusive seller, signed status, and more.
* Search for a specific title using the page level search.
* Sort the table by title, author, timeline, era, continuity, format, or ISBN using the column headers.
* Paginate through results — books are shown in pages you can navigate.
* Request a Title if you notice a missing title in the database.
* Perform actions on titles using the [Action Menu](../common/actionmenu.md).
* Use the [Bulk Add](..common/bulkadd.md) feature to add multiple titles to your collection.
