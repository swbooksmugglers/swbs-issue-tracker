# Legends Reference

The Legends Reference page is a reference guide for Star Wars Legends books. It displays three specialized lists related to collecting Legends books:

1. Earliest SFBC Gutter Codes: A list of the earliest published SFBC titles and their earliest published gutter codes.

1. MMPBs Published Exclusively with the Legends Banner: A list of titles that were originally published only in MMPB format with the Legends Banner.

1. Titles Published Exclusively in MMPB Format: A list of books that were only as mass market paperbacks.
