# Exclusives

The Exclusives page is a reference for retailer exclusives, convention specials, and limited edition variants.

<img width="1089" height="698" alt="exclusives" src="https://github.com/user-attachments/assets/81d3f4fd-691b-4593-9650-46eab867c4b4" />

Each book is grouped by retailer or convention.

Each group has their own:
* Search (similar to page level search)
* Sorting by title, ISBN, or author

The page also has [Action Menu](../common/actionmenu.md) options.
