# Edit My Book

Books can only be edited once you've added them to your collection. Think of books in the catalog as books in a store, you aren't able to personalize them until you've purchased a copy.

<img width="315" height="265" alt="action-menu" src="https://github.com/user-attachments/assets/187f4008-ae43-4722-a1f4-03cd8bfd83bb" />

To edit your books, navigate to the My Collection page and use the [Action Menu](actionmenu.md) on the book you would like to update.

<img width="639" height="744" alt="edit-my-book-form" src="https://github.com/user-attachments/assets/15c67b71-f52a-4554-b072-13dbd0bf8b4d" />

In the Edit My Book form, there will be several details that you can update.

* update the book's signed status by toggling the Signed switch by the author's name
* you can even describe the book's signature by selecting one or more description options
* track the printing, legends banner status, customizations, personal notes and other details

<img width="635" height="883" alt="edit-my-book-form-multi-author" src="https://github.com/user-attachments/assets/6ccfcb29-d816-4615-a9ad-e52416a95aa8" />

The Edit My Book form let's you track signatures on multi-author titles.

<img width="650" height="878" alt="edit-my-book-form-2" src="https://github.com/user-attachments/assets/b25645b7-b235-4500-84db-a30da4fbef24" />

If you're editing a special edition of a book (Goldsboro Brotherhood in this example). You'll notice that you add your number (My Number) and the signed toggle by Mike Chen's name is disabled, it's because the book came pre-signed from Goldsboro so you can't override this detail. You are able to change the signed status if you get personalization or inscription added to your copy of the book.
