# Bulk Add

<img width="169" height="56" alt="button" src="https://github.com/user-attachments/assets/04676fdc-c57a-4998-a6dd-c778cbaf6237" />

The `Bulk Add` feature allows you to select multiple titles and add them to your collection in a single transaction. 

When the `Bulk Add` button is clicked:
* the Bulk Add Toolbar is displayed.
* all Title groupings will auto expand.

## Using Bulk Add

### Selecting Specific Titles

<img width="1089" height="743" alt="select" src="https://github.com/user-attachments/assets/8207aece-b234-42cf-bbd0-75268590e4d4" />

You can select the each title that you want to add to your collection.

### Select All

<img width="1108" height="580" alt="select-all" src="https://github.com/user-attachments/assets/0d8d40c7-0f64-41a5-bd6d-c560d45babce" />

Clicking the checkbox on the Bulk Add Toolbar will automatically select all titles displayed.

### Progress Indicator

<img width="1099" height="105" alt="progress" src="https://github.com/user-attachments/assets/65f194b0-b799-40ec-885d-a0d30d0d3fb6" />

Once you have finished selecting the titles to add, click the `Add to Collection` button. This will begin adding the selected titles to your collection and display a progress indicator in the Bulk Add Toolbar.
