# My Reading List

The Reading List lets each user track their personal reading progress across books in the catalog.

When you add a book to your Reading List, you can assign a status (e.g. "Want to Read", "Reading", "Read") to the book. Any book in the Reading List even if they are not in your Collection.

<img width="1096" height="344" alt="reading-list" src="https://github.com/user-attachments/assets/d22702ba-829c-47e7-a51f-d4344b506aa9" />

There is a list for each reading status and a count for number of titles per list.
