# Star Wars Book Smugglers (SWBS) Docs & Issue Tracker

## Pronounciation

SWBS is pronounced as swibs.

“Swibs” would typically be pronounced like:

/swɪbz/ → “swibz”

It rhymes with:

* “ribs”
* “dibs”

Breakdown:

* “sw” as in “swim”
* “i” like the short “i” in “sit”
* “bs” becomes a “bz” sound at the end (common in English, like “tabs” → “tabz”)

So you’d say it quickly as: swibz
